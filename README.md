## Overview

Dynamic Trims makes armor trim item icons reflect their actual trim pattern instead of showing the same generic trim overlay for every pattern.

It keeps the mod focused on trim rendering, with shared common code and separate Fabric and NeoForge loader entrypoints.

---

## Features

- **Pattern-specific item icons** - Different trim patterns render as different inventory icons.
- **Armor trim rendering support** - Keeps item and armor trim rendering consistent.
- **Fabric and NeoForge builds** - Loader-specific jars from shared common code.
- **No dependency** - Runs without extra required mods.
- **Version branches** - Each Minecraft version can stay isolated on its own branch.

---

## Installation

1. Download the correct loader jar for your Minecraft version.
2. Place the jar in your `mods` folder.
3. Launch the game with Fabric Loader or NeoForge.

Use the branch/build that matches your Minecraft version.
